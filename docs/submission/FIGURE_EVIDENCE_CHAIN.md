# Figure Evidence Chain

Documenting the evidence chain for each figure generated by `scripts/make_defense_charts.py`.

## 1. fig_motivation.png
- **Figure title:** tau collapse + tail-latency inversion
- **Generator script and function:** `scripts/make_defense_charts.py::fig_motivation()`
- **Manifest experiment IDs:** (TBD)
- **Raw result paths:**
  - In-dist rate 4: `results/llama3-8b/vllm-4.0qps-*-fcfs-20260611-1*.json` and `vllm-4.0qps-*-opt-xxx-20260611-1*.json`
  - OOD rate 4: `results/llama3-8b/p2/part2_r4_fcfs_seed0.json` and `part2_r4_ltr_seed0.json` (via `ood()` function)
- **Values:** Computed from JSON (but data source is misleading for OOD).
- **Metric definition:** Mean of per-run values
- **P99 definition:** Per-run p99 averaged
- **Claims supported:** "Distribution shift degrades prediction quality" (comparing LMSYS in-dist tau to Phase D matched tau)
- **Claims NOT supported:** "LMSYS-trained predictor fails on ShareGPT" (because the p2 data used ShareGPT predictor)
- **Correction needed:** The motivation figure should use the original OOD files (pre-p2) if they exist, OR be relabeled. Original OOD files that DO use LMSYS predictor: `results/llama3-8b/vllm-4.0qps-*-ood-sharegpt.json` (without aging-val suffix).
