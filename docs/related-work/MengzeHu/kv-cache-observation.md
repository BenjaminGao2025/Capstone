# KV Cache Observation

This experiment tested prompt lengths from 128 to 4096 words and batch sizes up to 64 using Meta-Llama-3-8B-Instruct with vLLM. In this run, all tested prompt lengths reached batch size 64 successfully, so the data does not show a decreasing maximum batch size within the tested range. However, latency increased as prompt length grew, from about 0.679s for shorter prompts to about 1.475s at the longest tested length. The prompt length here is an approximate word-based length generated by repeating "hello", not an exact token count.
